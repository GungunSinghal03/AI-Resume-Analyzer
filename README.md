# AI Resume Analyzer

AI Resume Analyzer is a machine learning based web application that analyzes resumes against job descriptions and calculates a match score using NLP techniques like TF-IDF vectorization and cosine similarity.

## Features

- Upload resume in PDF format
- Paste job description
- Calculates ATS match score
- Uses NLP for text similarity analysis
